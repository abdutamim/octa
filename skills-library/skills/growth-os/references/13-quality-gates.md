# 13 — Quality Gates

Mandatory before any delivery.

---

## Red lines

```
✗ Invented numbers or results
✗ Fabricated testimonials
✗ Fake scarcity or fake countdown timers
✗ A promise larger than what can be delivered
✗ A guarantee that will not be honored
✗ Medical, financial, or legal claims without basis
✗ Defamatory comparison naming a competitor
```

**When there is no proof, substitute honestly:**
```
Instead of "got 40 clients for X"  →  "this is the method I use and why I trust it"
Instead of a made-up number        →  clear reasoning, a live demo, or a free trial
```

---

## General checklist (any output)

```
☐ Brief taken, or assumptions written out explicitly
☐ Diagnosis stated before the solution
☐ One named audience + one awareness stage
☐ Every recommendation carries a "why"
☐ Every step carries a "how" executable today
☐ A metric is attached
☐ One decisive next action
☐ No "all of these are good options" — there is a decision
☐ Written in the user's language and register
☐ Free of AI slop (see 07)
```

---

## Per-output checklists

### 30-day plan
```
☐ 30 distinct days, not one week repeated
☐ Each day: stage · pillar · format · idea · LITERAL hook · CTA · KPI
☐ Matches the hours the user actually has
☐ Includes batch production days and retro days
☐ No CTA above the stage ceiling
☐ 3:1 value-to-sell ratio respected
```

### Visual identity
```
☐ ≤ 4 colors in a 60/30/10 split
☐ Exactly two typefaces
☐ Logo works in black and white and at 24px
☐ Text contrast ≥ 4.5:1
☐ An explicit anti-style list exists
```

### Carousel / post
```
☐ Hook ≤ 6 words and legible at thumbnail size
☐ One accent per slide
☐ Fixed chassis
☐ Arabic RTL rules respected
☐ Last slide has exactly one action
☐ Caption adds rather than repeats
```

### Offer & landing page
```
☐ Promise + Mechanism + Proof + Guarantee + Bonuses all present
☐ One CTA, repeated
☐ FAQ addresses the real objections
☐ Mobile first, total cost visible early
```

### Ads
```
☐ Unit margin and max allowable CAC calculated before spend
☐ Measurement installed (pixel + events + UTM)
☐ Different angles, not different colors
☐ Explicit kill and scale rules written down
```

---

## Self-score before delivering

Score each 1–5:
```
1. Clarity of diagnosis
2. Precision of audience and awareness stage
3. Strength of the offer
4. Concreteness of language (Harry Dry ×3)
5. Immediate executability
6. Presence of metrics
7. Honesty and safety
```
**Below 28/35 → revise before delivering.**

## Diagnosis
