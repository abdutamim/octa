# Qualification And Discovery

Use this when the user needs to qualify a lead, decide whether to continue, or plan discovery.

## Fit Gate

| Field | Values | Purpose |
|---|---|---|
| problem_exists | yes / no / unknown | Is there a real problem or goal? |
| impact_size | small / medium / large / unknown | Is the issue worth solving now? |
| offer_fit | strong / partial / poor / unknown | Can the offer honestly help? |
| authority_path | decision-maker / influencer-with-path / no-path / unknown | Is there a path to decision? |
| timing | now / later / no-timeline / unknown | Is there a practical next step? |
| budget_clarity | clear / unclear / mismatch / unknown | Is budget understood enough for the next stage? |

## Decision Rules

| Decision | Rule | Next action |
|---|---|---|
| Pass | Real problem, meaningful impact, at least partial fit, and a decision path | Move to discovery or recommendation |
| Hold | One or more key fields unknown | Ask one clarifying question |
| Nurture | Strong fit but timing is later | Set a future follow-up with a clear reason |
| Disqualify | No real problem, poor fit, no decision path, or clear mismatch | Exit respectfully |

Budget can remain unknown temporarily when the other signals are strong, but it must be clarified before final commitment.

## Discovery Goals

Discover:

- Current situation.
- Desired outcome.
- Cost or consequence of staying the same.
- Constraints.
- Decision process.
- Success criteria.
- Risks or concerns.
- Next step the buyer would consider reasonable.

## Discovery Question Types

Use neutral placeholders and adapt to the user's context:

- Current state: "What is happening now?"
- Problem: "What is not working?"
- Impact: "What does that affect?"
- Desired state: "What would a better outcome look like?"
- Decision process: "Who needs to be involved?"
- Timing: "When would this need to be solved?"
- Constraints: "What could block this?"

Avoid interrogating the buyer. Ask one or two questions at a time.

## Disqualification

Disqualification protects both sides. When a lead is not a fit:

- State the mismatch plainly.
- Do not create pressure.
- Offer a neutral next step only if it is genuinely useful.
- Log the reason in CRM.
