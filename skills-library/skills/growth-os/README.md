# Growth OS v3

An end-to-end marketing skill: takes a project brief, diagnoses the real
bottleneck, then produces positioning, offer, brand identity, a content
system, hooks and scripts, copy, carousel specs, static ads, media buying,
pricing, a concrete 30-day plan, a monetization path, and scale systems —
**then renders the assets and publishes them.**

v3 adds the production floor on top of the v2 strategy brain:

- `16` pricing & product mix · `17` static ads · `18` media buying (Meta)
- `19` video craft (reel anatomy, film treatment, scene tricks)
- `20` production pipelines — Gemini images + vibe lock, Omni cinematic clips,
  Remotion kinetic Arabic reels, Gemini TTS, watch.mjs motion QA (real
  commands, real paths)
- `21` typography · `22` client transformation · `23` AI team & one-person
  business · `24` publishing (Meta Graph API scheduler) · `25` brand-course
  deltas (medium selection, Accordion Method, offer ladder)
- `profiles/` — per-brand data: `tamim.md` (default) + `_client-template.md`

## Install

Unzip into your skills directory:

```
skills/growth-os/
```

The agent loads `SKILL.md` first and pulls a reference file only when the
current stage needs it. Production (`20`) and publishing (`24`) reference
machine-local pipelines under `C:\Users\Admin\Desktop\Tamim Portfolio\` — on a
new machine or for a new client, scaffold via the carousel-forge skill and
update the profile.

```

references/16-25    v3: pricing, ads, media buying, video, production, publish
```
