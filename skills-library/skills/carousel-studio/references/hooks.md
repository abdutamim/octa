# الهوكات والكوبي — بنك وقوالب (أي براند)

## إزاي تكتب هوك

1. **ابدأ من العَرَض مش السبب.** الجمهور حاسس بالعَرَض («مفيش مبيعات»)
   مش عارف السبب («العرض مش واضح»). ابدأ من اللي **هو حاسس بيه**.
2. **اكتب ١٠ نسخ** مختلفين في الآلية (فضول / خسارة / عكس متوقع / رقم / مرآة).
3. **قصّرهم** — ٦ كلمات أو أقل في السطر.
4. **حدّد كلمة الضربة** — واحدة بس، هتاخد لون الأكسنت.
5. **اختبار الوحدة:** لو حطيت الغلاف لوحده، حد هيقف؟ لو لأ → ارمِه.

---

## قوالب الهوك (املأ الفراغ)

| النوع | القالب |
|---|---|
| **عكس المتوقع** | «**[اعتقاد شائع]** … غلط.» · «**[X]** مش المشكلة. **[Y]** هو المشكلة.» |
| **خسارة** | «كل يوم **[الحالة]**، إنت بتخسر **[النتيجة]**.» |
| **رقم** | «أول **[رقم]** **[وحدة]** بتحكم عليك.» |
| **مرآة** | «إنت **[موقف بيعيشه]**؟ **[سؤال]**» |
| **آلية/سر** | «كده **[الطرف]** بي**[فعل]**.» |
| **مقارنة** | «**[أ]** vs **[ب]** — الفرق **[نتيجة]**.» |
| **ليستة** | «**[رقم]** حاجات **[الجمهور]** بيغلطوا فيها» |
| **سؤال** | «عارف ليه **[نتيجة سيئة]** بيحصل؟» |
| **دليل شامل** | «الدليل الشامل لـ**[المجال]** في **[السنة]**» |
| **خبر عاجل** | «خبر عاجل — **[حدث]** يضرب **[المجال]**» |
| **قصة** | «يوم في حياة **[دور]** **[ظرف لافت]**…» |
| **مرجعية** | «**[شخصية/جهة]** أكّدتها رسميًا: **[اعتقاد]** مبقاش يشتغل» |

**صيغة الغلاف المتكررة:**
`[ادعاء/فضول بلون محايد] + [كلمة الضربة بالأكسنت] + [«…» أو «؟»]`

---

## قواعد كتابة النص (Body)

- **جملة–جملتين** لكل سلايد. أطول من كده = فكرة زيادة → سلايد جديد.
- **مخاطبة مباشرة:** إنت / اعمل / متعملش / احفظ.
- **ملموس بدل مجرّد:** «فورم طويل وشحن بيظهر فجأة» ✅ · «تجربة سيئة» ❌.
- **«…» و«؟»** آخر السطر بتسحب للسلايد اللي بعده.
- **الكاشيدة (ـــ)** لتسوية الأطراف وإحساس الديزاين المقصود.
- الأرقام لاتيني.

---

## قواعد الجريد (السلايد اللي بيتحفظ)

- **٤–٦ نقط**: **اسم قصير** (١–٢ كلمة) + **جملة تتنفّذ**.
- الاسم في **بادچ ملوّن** — لون مختلف لكل نقطة.
- الجملة ملموسة: «أبطأ من 3 ثواني؟ نص الزوّار مشيوا» ✅ · «السرعة مهمة» ❌.

---

## قواعد الـCTA

- **CTA واحد بس.**
- **مخاطرة صفر:** «من غير فلوس» · «رأي صريح حتى لو الشغل كويّس».
- **وضّح اللي هياخده** في ٣ نقط.
- **كلمة DM إنجليزي** قصيرة وسهلة الأتمتة.
- **غيّر بنية سلايد الـCTA** عن أي مرجع بتقلّده — دي أكتر حاجة بتفضح النسخ.

### أنماط CTA
- **DM:** «علّق/ابعت **[KEYWORD]** و**[هبعتلك]** **[العرض]**»
- **حفظ:** «احفظه، هترجعله أكتر من مرة»
- **شير:** «ابعته لحد محتاج يشوفه النهاردة»
- **كومنت:** «**[سؤال قصير]**؟ جاوبني بكلمة واحدة»

## أمثلة قبل/بعد

| ❌ ضعيف | ✅ قوي | ليه |
|---|---|---|
| «الموقع مهم لأي بيزنس» | «بتدفع إعلانات، وبتخسر.» | محدّد + خسارة + قصير |
| «تحسين تجربة المستخدم» | «هو مش بيماطل، هو مش واثق.» | يوصف موقف حقيقي |
| «راجع موقعك» | «بمشّطهولك بند بنـد.» | استعارة ملموسة + كاشيدة |
| «تواصل معنا» | «تحب أشوف موقعك؟ من غير فلوس» | مخاطرة صفر + سؤال |
| «المحتوى مهم» | «الكل بيزوّد إعلانات. وأنا بتفرّج.» | موقف + فضول |

## استعارة ممتدة (اختياري — بتدّي البراند صوت مميز)

اختار عالم واحد وخليه يمشي عبر السلسلة كلها. مثال (الأهوة البلدي):

| الاستعارة | المعنى |
|---|---|
| المعلّم | صاحب البراند الفاهم |
| الزبون | العميل المحتمل |
| الطُعم / السنّارة | الهوك / الرسالة |
| يقعّده يشرب الشاي | الاحتفاظ |
| الصيدة | التحويل |

بدل «الاحتفاظ بالعميل» → «تقعّده يشرب الشاي». نفس الدرس، صوت مميز.
