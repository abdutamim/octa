# References — Viral Content and Short Video System

## Goal

الفيديو القصير يجب أن يحقق:

- Reach.
- Authority.
- Trust.
- Leads.
- Sales.

## Core Rule

```text
Shareable Content wins.
```

## Shareability Triggers

- Mass Audience.
- Trend Jacking.
- Social Jacking.
- Relatable.
- Emotional.
- Evergreen.
- Extreme Idea.
- New Idea.
- New POV.
- Crisis.
- Value.
- FOMO.

## Script

```text
Persona → Pain/Outcome → Big Question → Dynamic Hook → Micro Hooks → Story/Value → Payoff → CTV
```

## Dynamic Hook

- Vocal.
- Text.
- Visual.
- Body Language.

## Micro Hooks

استخدم داخل الفيديو للحفاظ على الانتباه:

- أهم نقطة جاية.
- بس خلي بالك.
- المشكلة مش هنا.
- المفاجأة في الآخر.

## Shooting

- الموبايل يكفي.
- الصوت أهم من الصورة.
- الإضاءة أهم من الكاميرا.
- الكمية في البداية أهم من الكمال.

## Editing

- Captions.
- B-roll.
- Visual changes every few seconds.
- Edit for clarity, not flexing.
