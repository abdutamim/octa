## 1. Purpose

This is an **internal diagnostic aid for understanding why a deal, buyer, or conversation has stopped moving** — before any next reasoning path is chosen.

It is **not** a script, **not** a closing tool, **not** a pressure system, and **not** a production framework. A stall diagnosis is a hypothesis about *cause*, held provisionally and revised as facts arrive — never a verdict that licenses action against the buyer. The aid's only output is a better question: *what is actually unresolved for this buyer?* Stalls are usually information, not obstruction; this aid exists to read that information instead of overriding it.

## 2. Core Stall Principle

> **"Do not treat every stall as resistance."**

"Resistance" framing is the single most dangerous default in stalled deals, because it implies the remedy is *force* — more pain, more urgency, more proof, more asking. But the twelve stall types below have mutually incompatible remedies: the correct response to one is the harmful response to another. A buyer stalled on decision fear needs *less* pressure, not more pain (JOLT-layer evidence — proprietary, correlational — associates relitigating with worse outcomes). A buyer stalled on unclear impact needs more diagnosis, not a recommendation. A buyer stalled on genuine misfit needs an honest no-deal acknowledgment, not persistence.

Misreading a stall is therefore not just a tactical error — it is the main pathway by which an ethical reasoning process degrades into pressure *without anyone intending manipulation*. Diagnosis of the stall must precede any choice of move, for the same reason the Buyer-State Map's diagnostic principle precedes everything: most moves are state-conditional.

## 4. Value Gap vs Decision Fear

This is the single highest-stakes distinction in stall diagnosis — the branch point between stall types 1–4 (value side) and type 5 (fear side). It is source-backed: JOLT's central reframe is that lost-to-inaction deals split between status-quo preference and indecision, and that the remedies are opposite. *(Per the candidate file: the 44%/56% split and the ~84% relitigating-backfire figure are proprietary Tethr/ML statistics, correlational, methodology-cautioned — direction usable for internal reasoning, numbers not citable as claims.)*

**A) The buyer does not yet see enough value** — the problem, impact, future state, or fit was never fully established. The value case is genuinely incomplete.

**B) The buyer sees value but fears the decision** — the value case is complete and accepted; what remains is anxiety about choosing wrongly.

**What to check:**

- Can the buyer restate the problem, its impact, and the intended future state in their own words, unprompted? (If not → value side.)
- Has the buyer ever explicitly affirmed the value case — and do their *current* concerns contain any new substance, or do they recycle resolved ground? (Affirmed + no new substance → fear side.)
- Do new requests change the decision picture when fulfilled? (Value-side requests resolve things; fear-side requests are replaced by new ones.)
- Is the language about the *offer* ("does it do X?") or about the *decision* ("what if we're wrong?", "is now the time?")?

**Signs of a value gap (A):** questions still aimed at problem/solution substance; impact never quantified from buyer facts; the buyer's own narrative of why change matters is thin or borrowed from the seller; stall appeared early, before any value affirmation existed.

**Signs of decision fear (B):** stall appeared *after* explicit value agreement; resolved concerns resurface in new costumes; validation-seeking that doesn't update the picture; personal-consequence language; the buyer defends the solution to others yet won't commit.

**Dangerous misread — each direction fails differently:**

- **B read as A** (the common one): more pain, more implication, more urgency poured onto an anxious, already-convinced buyer → fear amplification, fails Ethics Screen Gate 5, and per the JOLT layer correlates with *worse* outcomes. Unethical and ineffective simultaneously.
- **A read as B** *(Original extension — this reverse direction is stated here explicitly; the sources develop only the B-read-as-A direction)*: risk-reduction and recommendation applied to a buyer whose problem was never established → steering without diagnosis, violating buyer-owned discovery and JOLT's own entry condition (value understood first).

**Safer internal redirection:** treat the distinction as a *gate*, not a guess. Before any fear-side reasoning (risk reduction, bounded exploration, recommendation concepts), require evidence that the value case was explicitly affirmed by the buyer. Before any value-side reasoning (impact development), check whether value was already affirmed — if it was, more pain is the wrong tool by definition. When genuinely undecidable from available facts, the next step is more diagnosis, never a default to either remedy.

## 5. Stall-to-Source Routing

- **SPIN / Gap** own stall types 1–4 (the value side): problem existence, impact development, current-state/future-state specification, root cause, and explicit-need formation. They are the default first lens because every other path assumes their work is complete.
- **JOLT** owns types 5–6 (the fear side): decision fear, fear of the wrong choice, and option overload — strictly *after* value is understood, never as a substitute for establishing it.
- **Getting to Yes** owns types 7, 8, and 12 (the negotiation and ethics side): criteria conflict, interests behind positions, objective standards, fair procedure, BATNA as self-protection, and no-deal legitimacy — and supplies the anti-pressure boundary everywhere else.
- **Challenger** contributes only to type 1 (and partially type 9's stakeholder tailoring): bounded teaching/reframing when the buyer may genuinely not see a problem the evidence suggests is real — as a hypothesis the buyer validates, with tension unapproved.
- **Influence** routes to no stall type as a tactics source. It is the detection lens — most intensively on types 10 and 11 — asking one question: are the cues operating in this stall genuine or fabricated, and is anyone (including our side) exploiting shortcuts instead of evidence?
- **Type 9** has no fully adequate owner (Source-Gap Map v2 buying-committee gap); reasoning there stays provisional until a covering source is approved.

| Treating an unclear problem as indecision (type 1 read as type 5) | Applies recommendation/narrowing where no validated problem exists — steering without diagnosis, violating JOLT's own entry condition | Buyer-owned discovery (HAD-002 principles 1–2); JOLT entry boundary | Return to first diagnosis: establish whether a real problem exists before any fear-side reasoning |

| Treating a legitimate no-deal as an objection (type 12 read as a closing challenge) | Converts honest misfit into a conversion project; every subsequent move is structurally pressure because the buyer's interest is no longer the objective | Gate 10; HAD-002 principle 9; GTY no-agreement ethics | Run the fit assessment honestly; if the buyer's alternative is better on their criteria, acknowledge it — blocked, not redirected, if Gate 10 fails |

## 7. Internal Review Workflow

1. **Identify the apparent stall.** State what stopped, when, and what changed around that moment.
2. **Separate facts from assumptions.** List the buyer facts in evidence; everything else is assumption — and stalls are where assumptions concentrate.
3. **Map the stall to buyer state** using the Buyer-State Diagnostic Map (§3 of that file); form a stall-type hypothesis from §3 here, held provisionally.
4. **Check value clarity.** Can the buyer restate problem, impact, and future state? (§4 gate, value side.)
5. **Check decision risk.** Was value explicitly affirmed? Are concerns recycling without new substance? (§4 gate, fear side.)
6. **Check criteria / stakeholder / trust issues.** If neither value nor fear explains the stall, test types 7–10: conflicting standards, organizational friction, verification needs.
7. **Route to source logic** (§5), respecting entry conditions — JOLT's especially.
8. **Run the Internal Ethics Screen** on the selected path — all 12 gates, with §6 here as the targeted re-check.
9. **Decide output category** (Ethics Screen §6, lowest category wins).
10. **Keep output internal** — marked `INTERNAL CONTROLLED DEVELOPMENT — NOT PRODUCTION APPROVED` — unless future explicit approval allows implementation.

## 8. Relationship to Buyer-State Map and Ethics Screen

The three artifacts now form a sequence with distinct jobs:

- The **Buyer-State Diagnostic Map** identifies *where the buyer is* — their decision state.
- This **Stall-Diagnosis Aid** explains *why motion has stopped* — the causal read on the stall. The two overlap deliberately (stall types map onto buyer states) but answer different questions: a buyer can be in a state without being stalled, and a stall's cause can sit outside the buyer entirely (type 11).
- The **Internal Ethics Screen** decides *whether the proposed reasoning path may continue* — gates, categories, and redirections.

**If they conflict, the Ethics Screen wins.** Beneath all three, **HAD-001 remains the highest boundary** — no diagnostic conclusion from this aid can unblock a blocked concept or convert a defensive-only concept to offensive use. *(Original extension — this three-artifact precedence chain extends the two-artifact precedence rule already labeled in the Buyer-State Map §7.)*

Standing flags carried over from the Buyer-State Map: type 11 work is always defensive-only, and type 12 conclusions must never be softened into retention-of-pursuit — a Gate 10 failure there is blocked, not redirected.
