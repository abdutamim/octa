# Landing Pages — Structure, Conversion, Imagery

## The 4 quality levels (know which you're shipping)
- **L1 (~$500, template)**: works, zero decisions, stock images, flat nav, haphazard color, no animation.
- **L2 (~$2k)**: stacked hero, real product screenshot replaces stock, palette derived from the product shot, matched CTA labels, simple load animations.
- **L3 (~$6–10k)**: cropped/zoomed screenshot moments, vertical framing lines, bento, mega menu, logo wall + badges, smooth animation. Known L3 failure: hierarchy overdone — headline drowning the subline.
- **L4 (>$10k)**: purpose-crafted visuals, molded organic layout, brand color threaded through everything, micro-detail animation, immaculate flow. No custom 3D required — just attention to detail.
- Copy ladder up the levels: vague & long → short & punchy "what it does" → **"how it helps"** ("collect and analyze data" → "turn data into decisions").

## Page skeleton (default, reorder with intent)
Hero (+ CTA) → logo/social-proof bar → how-it-works (oversized images) → feature tabs or bento (cut ~90% of the text, enlarge images) → mission/statement section (image + short text + button, stupid simple) → pricing → testimonials → bold-type CTA over image → FAQ → footer (conventional, don't innovate).
- If the header has no CTA, the page needs a CTA section near the top.
- Roadmap sections BEFORE designing; condense redundant pages into one flow.
- Sections must segue (logo wall → analytics; screenshot fade-out → features) so the page itself encourages scrolling — not sections dropped on top of each other.
- Privacy/trust section is mandatory for any product touching user data or money.

## Conversion rules
- 5-second test on the wireframe: if a fast scroller can't get the idea in 5s, the structure fails. Blocks of text, simple illustrations, bold numbers beat fragments and ornament.
- State what the product IS immediately; show the actual product early. Don't bury the name/category at 12px.
- One actionable headline that promises exactly what the thing does beats clever copy. Nobody reads text blocks in a hero.
- Logo/social-proof bar: the single most common section (41/50 top SaaS sites) — static row or marquee with edge fade. With zero context, users assume "important companies use this."
- Social proof = badges, logo walls, review links — not a testimonial paragraph inside the hero.
- Comparison-with-competitors as social proof: via testimonial or head-on table.
- For products whose core action is typing: a live input as the hero CTA (user is already mid-action). A search input can be the final CTA (store locator).
- Sanity-check the actual offer copy ("free shipping over $500"?) — not just the pixels.
- Conversion sites stay simple and usable; awareness/brand sites can go wild. Decide which you're building before adding effects.
- One primary CTA per screen; 404 pages are the sanctioned personality zone.

## Sector fit ("says who it's for, designs like it's never met them")
- If the audience is restaurants, the imagery/texture/type should evoke restaurants: sector photos around the hero, palette pulled FROM the photos, serif accents like a menu. Zero images = telltale robotic vibe-coded site.
- Decorative context elements (coins, invoices, product objects) communicate what the product is before a word is read — removing them empties the page, doesn't clean it. Match their density to brand vibe: playful ↔ professional.
- Visual identity comes from feeling, not formula: one moody image, cropped, darkened, noise layered, brand name set on it — extend from there.
- Steal patterns from adjacent products of the same brand so the design stays on-brand; when stuck between two symbols, pick the one the brand already owns.

## Imagery
- Screenshots > stock, always. Then crop/zoom to the exact feature being sold. At L4, purpose-craft the visual.
- A high-quality hero asset makes or breaks the page; the image must be CALM where text overlaps; never obstruct the focal point (nudge text first; text-behind-subject cutout as the last resort).
- Single object → cut background + break the box. Product photo → crop into a detail. Wide landscape → overlay + headline as a brand-message section. Mask images into shapes matching the site's language.
- Giant blow-ups need high-res sources (Google Images → Tools → Large).
- Interlude photo strips: crop aggressively wide, gradient scrim under any text.
- AI for mockup SCENES, not UI: "MacBook on an orange leather chair, green screen on display, blurred background, soft shadows, moody lighting, lived-in" → chroma-key, skew your real UI in. Environmental imperfections sell realism.
- Pull the brand palette out of the photography for guaranteed cohesion.
- One rotating 3D hero (SVG → Spline/Blender → video) is so engaging the rest needs minimal decoration; watch for dark frames across the rotation.

## Presenting the work (portfolio/client)
- Portfolio/social: plain background (darkened desaturated accent — never brighter than the design) + faint shadow; glow circles in dark mode; explode the UI off-frame; skew ~2°/−14°; pop a key frame out with offset+shadow; collages offset and slightly rotated, never perfect grids.
- Clients: confidence, not wow — device mockups in realistic contexts + prototypes. Don't describe, show: gestures, modal entrances, delete animations.
- Landing pages get collages/skews; dashboards get one zoomed section, lightly animated (full-page dashboard collages fail — detail too fine).
