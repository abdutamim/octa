# References — Offer Crafting and Power Guarantee

## Product vs Offer

```text
Product = ماذا يأخذ العميل؟
Offer = لماذا يشتري الآن ومنك أنت وهو مطمئن؟
```

## Irresistible Offer Formula

```text
Promise + Mechanism + Proof + Guarantee + Bonuses = Irresistible Offer
```

## 1. Promise

الوعد لازم يكون:

- نتيجة نهائية واضحة.
- قابلة للقياس.
- في مدة.
- مرتبطة بعقبة.

صيغة:

```text
هتتعلم/تحقق/تحصل على [نتيجة] في [مدة] حتى لو [عقبة].
```

## 2. Mechanism

الآلية هي “إزاي بطريقة مختلفة”.

```text
مش كورس ماركتنج؛ دي Strategy X.
مش دايت؛ دي Metabolism Reset.
مش خدمة إعلانات؛ ده Full-Funnel Growth System.
```

## 3. Proof

استخدم نوعين على الأقل:

- Results.
- Story.
- Screenshots.
- Dashboard.
- Logical Proof.
- Demo.
- Case Study.
- Reviews.

## 4. Guarantee

الضمان أداة بيع. يبنى على:

- نقل المخاطرة من العميل للبزنس.
- وضوح النتيجة.
- قابلية القياس.
- قوة المنتج.

أنواع:

```text
Money Back
Conditional
Reverse Guarantee
Partial Guarantee
Trial Before Pay
Cashback on Delay
```

## 5. Bonuses

كل اعتراض = Bonus.

| Objection | Bonus |
|---|---|
| معنديش وقت | خطة 30 دقيقة يوميًا |
| غالي | Templates/Checklists |
| جربت وفشلت | متابعة أو مراجعة |
| مش عارف أبدأ | Start Here Session |

## 6. Stack Value

اعرض القيمة قبل السعر.

```text
Main Program: 3000
Templates: 1000
Review: 1500
Community: 1000
Total: 6500
Today: 1497
```

## 7. Scarcity

استخدمها فقط لو حقيقية:

- عدد محدود.
- وقت محدود.
- مخزون محدود.
- سعر قبل الزيادة.

## 8. Offer Audit Questions

```text
هل الوعد واضح؟
هل فيه مدة؟
هل فيه نتيجة قابلة للقياس؟
هل فيه Mechanism مختلف؟
هل فيه Proof؟
هل الضمان يزيل الخوف الحقيقي؟
هل البونصات تكسر اعتراضات؟
هل السعر مبرر؟
هل الندرة حقيقية؟
هل الأوبريشن يقدر ينفذ؟
```

## Product Naming (من بعد خلق الـ USP)

الـ Product Messages في الإيكومرس بتبدأ من الـ Product Naming بعد ما تخلق الـ USP. استراتيجية مجرّبة:
`Product Name = أول حرف من اسم البراند + prefix/suffix للـ USP باستخدام tweak & blend words`
وبعدين راجع 3 معايير أساسية: **اسم قصير + سهل النطق + سهل تفتكره**.
