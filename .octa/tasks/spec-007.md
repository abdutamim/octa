# Task: spec 007 — Voice: Gemini Live, wake word, push-to-talk

Read `docs/06-SPECS.md` section 007, `docs/07-DECISIONS.md` D1/D7, `docs/01-RUNTIME-CONTRACT.md` §6 and §9, `docs/00-OCTA-ASSISTANT.md` §3–4. Copy from the reference app: `electron/core/dictation.ts` (mic capture + trigger), `electron/input/trigger.ts` (global hotkey / mouse), the overlay (`src/overlay/Overlay.tsx`) as the base for the voice indicator, and their tests. Reference Gemini transport is already copied (spec 000).

Build:
1. `electron/cloud/gemini-live.ts` — WebSocket session to the Gemini Live API (bidirectional native audio). Pick the newest model that supports native audio with Arabic: query the models list at startup with the AI Studio key and choose the newest id matching `/live|native-audio/`; store the choice in settings with a manual override. Stream mic PCM in, play audio out, handle interruption (barge-in), transcript events, and a system instruction with the language mirror rule and the persona ("Octa, يرد بنفس لغة المستخدم، مصري لو المستخدم مصري").
2. Wake word: local detector in the main process using openWakeWord (ONNX runtime) or Porcupine free tier — choose the one that can ship a custom "أوكتا / يا أوكتا" model offline; document how the model file is trained/obtained in `SETUP.md`. Audio never leaves the machine until the wake word fires. Greeting turn on wake: "إيه يا عميل، عايز إيه؟" (configurable text). Push-to-talk on a configurable key (Settings), reusing the copied trigger code. Both can be on at once.
3. Language mirror §9: detect on the final transcript of each user turn (script ratio + Gemini language hint), store on the conversation, pass to the planner.
4. Read-back: `speak(text)` for planner questions and job results; spoken "approve / موافق" is accepted only within 60 s after a read-back of the exact payload, via `workflows:gate:approve` with `channel:'voice'`; otherwise Octa says it needs the read-back first.
5. TTS fallback: when Live is unavailable, use Gemini TTS (`gemini-3.5-flash` TTS endpoint via the copied client) + the copied STT path.
6. Octa panel pieces: `src/components/VoiceBar.tsx` (state: idle / listening / thinking / speaking, transcript, interrupt button) mounted in the app shell; overlay indicator when the window is hidden.
7. Tests: language detection fixtures (Arabic, English, mixed), approve-after-read-back rule, wake-word → session state machine with a fake detector, Live message framing with recorded fixtures. Manual verification of latency and false-wake rate on this machine; record the numbers in the report.
