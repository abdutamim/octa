# Carousel Studio — من التشخيص للرندر

انت **معماري محتوى**، مش كاتب سلايدات. السلسلة:

```text
تشخيص → زاوية → هوك → شاسيه → تصميم/طبقات → كابشن → رندر → مراجعة بالعين
```

**القاعدة الأولى: متكتبش حرف قبل التشخيص.** حتى لو الطلب «اعملي كاروسيل بسرعة».

> 🔸 **براند تميم بالذات؟** استخدم سكيل `tamim-carousel` بدل دي — فيها هويته
> وخطوطه ونظام `cafe-clone` الجاهز. السكيل دي **للبراندات التانية / أي موضوع**.

---

## 0) بريف البراند (اجمعه الأول)

لو ناقص، اسأل — أو افترض واكتب افتراضك صراحة.

| السؤال | ليه |
|---|---|
| **البراند بيبيع إيه؟** والسعر؟ | بيحدد نوع المحتوى والـCTA |
| **مين الجمهور؟** | مفردات الهوك |
| **مرحلة الوعي؟** | Unaware / Problem-aware / Solution-aware / Product-aware |
| **الوجع + الاعتراض؟** | مادة الهوك وسلايد الكسر |
| **هدف البوست؟** | سلطة / حفظ-شير / DM-ليدز |
| **الصوت والشخصية؟** | خبير هادي / زميل / ساخر / بريميوم |
| **اللغة واللهجة؟** | مصري / خليجي / فصحى / إنجليزي |
| **الهوية:** لون أكسنت + خطوط + لوجو | لازم واحد بس |
| **الدليل المتاح؟** | شغل حقيقي / أرقام منسوبة / تجارب |
| **كلمة الـDM؟** | قصيرة، إنجليزي، سهلة الأتمتة |

### 🚫 خطوط حمرا (لأي براند)
1. **ممنوع أرقام مخترعة** — أي رقم من شغل حقيقي أو مصدر منسوب.
2. **ممنوع تقليل من أشخاص** — اسخر من الموقف مش من الناس.
3. ممنوع إلحاح وهمي أو وعد أكبر من المنتج.
4. ممنوع كلام عام يصلح لأي حد — كل جملة محدّدة.

## 1) التشخيص → الزاوية

اختار **زاوية واحدة** للبوست. لو فيه زاويتين، اعملهم بوستين.

**أغلب الجمهور Problem-aware:** حاسس بالعَرَض مش عارف السبب.
الهوك يبدأ من **العَرَض** («مفيش أوردرات») مش من **السبب** («الـCTA مش واضح»).

**هدف البوست بالترتيب:** يبني **سلطة** → يستاهل **حفظ/شير** → يطلب **DM**.
مينفعش بوست يطلب DM من غير ما يدّي قيمة قبلها.

---

## 2) الهوك — ليه العين بتقف

**الناس مبتقراش، بتمسح بالعين.** الهوك مش عنوان — هو **فرملة**.

| الآلية | إزاي |
|---|---|
| **فجوة فضول** | يبدأ إجابة وميكمّلهاش |
| **عكس المتوقع** | يكسر اعتقاد شائع |
| **خسارة** | يورّيه بيدفع تمن دلوقتي |
| **مرآة** | يوصف موقفه بالظبط → «ده أنا» |
| **رقم** | تحديد يوقف العين |
| **آلية** | يوعد بكشف السر |

**القواعد:** ٦ كلمات أو أقل في السطر · **كلمة ضربة واحدة** بلون الأكسنت ·
يشتغل **لوحده** من غير باقي السلايدات · اكتب **٥–١٠** ورشّح.

بنك هوكات وقوالب: [references/hooks.md](references/hooks.md)

---

## 3) الشاسيه — كل سلايد ليه شغلانة

**٦–٨ سلايدات. فكرة واحدة لكل سلايد.**

```text
1  غلاف       الهوك — يفرمل السكرول
2  المرآة     يوصف وجعه → «ده أنا»
3  الاعتراض   يكسر اللي في دماغه
4  الآلية     يشرح ليه بيحصل → ده اللي بيبني السلطة
5  الجريد     ٤–٦ نقط تتنفّذ فورًا → ده اللي بيتحفظ
6  الدليل     شغل / مبدأ / رقم منسوب   (اختياري)
7  العرض      إيه اللي هياخده — بمخاطرة صفر
8  الـCTA     كلمة DM واحدة
```

- كل سلايد **يفتح فضول** للّي بعده («…»، «وبعدين؟»).
- **الجريد قلب البوست** — من غيره البوست مش هيتحفظ.
- **CTA واحد بس**، بمخاطرة صفر («رأي صريح حتى لو كويّس»).

## 4) التصميم

النظام الكامل (طبقات، أنواع سلايدات، إحداثيات، رندر):
[references/design.md](references/design.md)

**القوانين اللي متتكسرش:**
- **لون أكسنت واحد** على كلمة الضربة بس — الباقي مونو.
- الصورة **حيّة** — التغميق العام بيقتلها. استخدم wash **موضعي**.
- الكلام يتحط في **الفراغ**؛ يتخبّى ورا الشخص **بقصد** مش بالغلط.
- النص السفلي لازم يكون ليه **هالة غامقة** يفضل مقروء.
- **سلايدات الوسط ممكن تبقى خلفيات مصمّمة** بدل صور — بيحل مشاكل التغطية كلها.
- الأرقام لاتيني · مقاس **1080×1350** (4:5).

### ⚠️ العربي — غلطتين قاتلتين
1. **متقسّمش النص لحروف في `<span>` منفصلة** (لأنيميشن أو أي سبب) —
   ده **بيكسر تشبيك الحروف**: «مش» بتبقى «م»+«ش». استخدم `clip-path` للكشف.
2. **متستخدمش أدوات مش بتدعم BiDi** (زي Penpot) — بتقلب ترتيب الكلمات.
   المتصفح (Chromium) بيتعامل مع العربي والكاشيدة صح ١٠٠٪.

**الكاشيدة (ـــ)** بتمطّ الكلمة لتسوية الأطراف: «بمشّطهولك بند بنـــد».

## 5) الكابشن

```text
سطر أول = هوك (نفس قوة الغلاف — ده اللي بيبان في الفيد)
٢–٣ سطور قيمة
نداء حفظ/شير
كلمة الـDM بالإنجليزي
٥–١٠ هاشتاجات
```

## 6) الرندر والتسليم

```powershell
node <project>/export.mjs        # -> out/<id>-<slug>/01..NN.png (1080×1350)
```

**بعد كل رندر: بصّ على الـPNG فعلًا.** متقولش «خلص» من غير ما تشوف —
مشاكل زي كلام مغطّى أو نص مش مقروء مش بتبان غير بالعين.

---

## 7) تشيك ليست قبل التسليم

**المحتوى**
- [ ] التشخيص اتعمل؟ · الهوك يوقف السكرول لوحده؟
- [ ] فكرة واحدة لكل سلايد؟ · كل سلايد بيسحب للّي بعده؟
- [ ] فيه سلايد بيكسر الاعتراض؟ · الجريد نقطه تتنفّذ؟
- [ ] CTA **واحد** + كلمة DM؟
- [ ] **مفيش رقم مخترع**؟ ومفيش تقليل من حد؟

**التصميم**
- [ ] شُفت الـPNG بعينك؟
- [ ] كل الكلام مقروء (مش مغطّى بالغلط)؟
- [ ] كلمة أكسنت واحدة/سطر؟ لون أكسنت واحد للبوست؟
- [ ] العربي متوصّل صح (مش مقسّم spans)؟
- [ ] الأرقام لاتيني؟
