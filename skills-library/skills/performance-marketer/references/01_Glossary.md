# References — Marketing Glossary

كل مصطلح هنا لازم يتفهم كأداة تشخيص لا كرقم منفصل.

| Term | Meaning | Practical Use |
|---|---|---|
| CAC | Customer Acquisition Cost | تكلفة اكتساب العميل. إجمالي تكلفة التسويق والمبيعات المطلوبة لجلب عميل جديد. الصيغة: Marketing + Sales Cost / New Customers. لا يُحكم عليه وحده بل مقابل LTV والهامش وفترة استرداد التكلفة. |
| CTR | Click Through Rate | معدل النقر. الصيغة العامة: Clicks / Impressions × 100. يقيس جاذبية الإعلان أو ارتباط الرسالة. CTR العام يشمل كل النقرات، وLink CTR يركز على نقرات الرابط. |
| CPM | Cost Per Mille | تكلفة الألف ظهور. الصيغة: Spend / Impressions × 1000. يتأثر بالمزاد والجمهور والجغرافيا والموسم وجودة الإعلان. |
| CPC | Cost Per Click | تكلفة النقرة. الصيغة: Spend / Clicks. قد يكون CPC عام أو Link CPC أو Outbound CPC حسب نوع النقر. |
| CPP | Cost Per Purchase | تكلفة عملية الشراء. أحيانًا يسمى CPA في سياق الشراء. الصيغة: Spend / Purchases. |
| CPA | Cost Per Action/Acquisition | تكلفة الفعل المطلوب، مثل Lead أو Purchase أو Booking. يجب تعريف الفعل بوضوح. |
| ROAS | Return On Ad Spend | العائد من الإنفاق الإعلاني. الصيغة: Revenue / Ad Spend. ROAS ليس Profit لأنه لا يخصم تكلفة المنتج والشحن والمرتجعات. |
| ROI | Return On Investment | العائد على الاستثمار بعد احتساب كل التكاليف. الصيغة: Net Profit / Total Investment × 100. |
| AOV | Average Order Value | متوسط قيمة الطلب. الصيغة: Revenue / Orders. مهم لتحديد قدرة تحمل CAC. |
| LTV / CLV | Lifetime Value / Customer Lifetime Value | قيمة العميل طوال فترة علاقته بالبزنس. الصيغة المبسطة: Profit per order × Purchase frequency × Retention period. |
| CVR | Conversion Rate | معدل التحويل. الصيغة: Conversions / Visitors or Clicks × 100 حسب المرحلة. |
| LPV | Landing Page View | عدد المرات التي فتحت فيها الصفحة بالفعل بعد الضغط على الإعلان. |
| LPV Rate | Landing Page View Rate | الصيغة: LPV / Outbound Clicks × 100. انخفاضه يعني مشكلة تحميل/سرعة/رابط/توافق. |
| VC | View Content | حدث مشاهدة محتوى أو صفحة منتج. مهم لمعرفة من وصل فعلاً للمنتج. |
| ATC | Add To Cart | حدث إضافة للسلة. انخفاضه بعد View Content يشير لسعر/عرض/ثقة/معلومات منتج/شحن. |
| IC | Initiate Checkout | حدث بدء الدفع. انخفاضه بعد ATC يشير لتكاليف مفاجئة أو Checkout معقد أو وسائل دفع محدودة. |
| Purchase | Purchase Event | حدث الشراء. يجب ربطه بقيمة Revenue إن أمكن. |
| Frequency | Frequency | متوسط عدد مرات ظهور الإعلان لنفس الشخص. ارتفاعه مع تدهور النتائج يشير إلى Fatigue. |
| Reach | Reach | عدد الأشخاص الفريدين الذين شاهدوا الإعلان أو المحتوى. |
| Impressions | Impressions | عدد مرات الظهور الكلي، حتى لو لنفس الشخص أكثر من مرة. |
| Pixel | Meta Pixel | كود تتبع يرسل أحداث الموقع إلى Meta. |
| Event | Event | فعل يحدث من المستخدم مثل Page View, Add to Cart, Purchase. |
| Key Event | Key Event in GA4 | الحدث المهم للبزنس. كان يسمى Conversion سابقًا في GA4. |
| UTM | Urchin Tracking Module | باراميترات تضاف للرابط لمعرفة source/medium/campaign/content/term في GA4. |
| Source | Traffic Source | المصدر مثل facebook, google, tiktok. |
| Medium | Traffic Medium | نوع الترافيك مثل paid_social, cpc, organic, referral, email. |
| CBO | Campaign Budget Optimization | ميزانية على مستوى الحملة، والمنصة توزعها على Ad Sets. |
| ABO | Ad Set Budget Optimization | ميزانية على مستوى Ad Set، يعطي تحكمًا أكبر في الاختبار. |
| ASC | Advantage+ Shopping Campaign | نوع حملات Meta مؤتمت للتجارة الإلكترونية، يعتمد على إشارات قوية وكرياتيفات متعددة. |
| Broad Targeting | Broad | استهداف واسع بدون Interests، يعتمد على الكرييتف والسيجنالز. |
| Retargeting | Retargeting | إعادة استهداف من تفاعل أو زار أو أضاف للسلة أو بدأ الدفع أو اشترى. |
| TOF | Top of Funnel | مرحلة أعلى الفانل: جمهور بارد، وعي وتعليم. |
| MOF | Middle of Funnel | مرحلة منتصف الفانل: جمهور دافئ، إثبات واعتراضات وثقة. |
| BOF | Bottom of Funnel | مرحلة أسفل الفانل: جمهور قريب من الشراء، عرض وضمان وندرة. |
| CRM | Customer Relationship Management | نظام إدارة علاقة العملاء والمتابعة والبيانات والتكرار. |
| CRO | Conversion Rate Optimization | تحسين معدل التحويل في الصفحة أو الفانل أو التجربة. |
| A/B Test | A/B Testing | اختبار نسختين أو أكثر من متغير واحد لمعرفة الأفضل. |
| Hook | Hook | أول عنصر يوقف انتباه العميل في إعلان أو فيديو أو كوبي. |
| CTA | Call To Action | طلب فعل مباشر من العميل: اشترِ، سجل، احجز. |
| CTV | Call To Value | طلب متابعة أو فعل مرتبط بالقيمة التي سيحصل عليها العميل لاحقًا. |
| USP | Unique Selling Proposition | التميّز الأساسي الذي يجعل عرضك مختلفًا. |
| ICP | Ideal Customer Profile | وصف العميل المثالي الذي يحقق أفضل عائد وقيمة. |
| Buyer Persona | Buyer Persona | تمثيل بحثي للعميل، ويجب أن يتجاوز السن والجنس إلى نفسية وسلوك شراء. |
| Dream Buyer Persona | Dream Buyer Persona | العميل المثالي العميق الذي تبني له المنتج والرسالة والعرض. |
| LMF | Largest Market Formula | مصفوفة تقسيم السوق إلى Buying Now 3%, Information Gathering 17%, Problem Aware 20%, Not Problem Aware 60%. |
| Lead Magnet | Lead Magnet | قيمة مجانية أو منخفضة التكلفة لجمع بيانات عميل محتمل وبناء الثقة. |
| Loss Leader | Loss Leader | عرض بسعر زهيد أو مجاني لاكتساب العميل ثم الربح من upsell/retention. |
| Upsell | Upselling | بيع نسخة أعلى أو أغلى للعميل. |
| Cross-sell | Cross-selling | بيع منتج مكمل للمنتج الأساسي. |
| Scarcity | Scarcity | ندرة حقيقية في الوقت أو العدد أو المخزون لتحفيز القرار. |
| Guarantee | Guarantee | ضمان يقلل مخاطرة العميل ويزيد الثقة. |
| Mechanism | Unique Mechanism | الطريقة المختلفة التي تجعل وعدك قابلًا للتصديق ومميزًا. |
| Proof | Proof | دليل يدعم الوعد: نتائج، قصص، Screenshots، Demonstration، Reviews. |
| Stack Value | Stack Value | عرض مكونات القيمة وأسعارها قبل السعر النهائي. |
| Message Match | Message Match | تطابق الرسالة بين الإعلان والصفحة والعرض. |
| Bounce Rate | Bounce Rate | نسبة من يغادرون دون تفاعل مهم. في السياق العملي يعني الصفحة لا تكمل الوعد أو بطيئة أو غير مناسبة. |
| Attribution | Attribution | طريقة إسناد التحويل لمصدر أو حملة أو لمسة تسويقية. |
