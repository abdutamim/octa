# References — Copywriting Formulas Library (26 معادلة)

بتبني variations مختلفة في الـ angles والكوبي عشان تختبرها وتحدد الـ winner وتـ scale. الملف ده مكتبة معادلات — جرّب منتجك على كذا واحدة، هتلاقي 1-2 منهم PERFECT MATCH لهدفك. AIDA أساسية زي السلم الموسيقي، لكن مش الوحيدة.

## المجموعة الأساسية
1. **AIDA** — Attention → Interest → Desire → Action. الأشهر والأساس.
2. **المعادلة الأبسط (4 أسئلة)**: إيه اللي عندي ليك؟ / ده هيعمل إيه ليك؟ / أنا مين؟ / تعمل إيه دلوقتي (CTA)؟
3. **SSS (Star–Story–Solution)**: النجم (إنت/عميل/المنتج) → قصة المشكلة → الحل.
4. **PAS (Problem–Agitate–Solution)**: المشكلة → التضخيم العاطفي → الحل. (المفضّلة عند الأغلبية.)
5. **PASTOR** = PAS متنكّرة بتركيز على القصة والعاطفة: Person/Problem/Pain → Amplify → Story/Solution/System → Testimonials → Offer (80% من الوقت على التحوّل) → Response.

## معادلات الانتباه/الإقناع
6. **AICPBSAWN**: Attention, Interest, Credibility, Prove, Benefits, Scarcity, Action, Warn, Now. (المعادلة الذهبية.)
7. **Gary Halbert**: اجذب الانتباه → ليه يهتموا → ليه يصدقوك → أثبت → عدّد الفوائد → إزاي يطلبوا → اطلب الطلب فوراً.
8. **ACCA**: Awareness → Comprehension → Conviction → Action. (الفرق عن AIDA: Comprehension بتركّز على الفهم، Conviction أقوى من Desire.)
9. **Robert Collier**: Attention → Interest → Description → Persuasion → Proof → Close.
10. **Earle A. Buckley**: Interest → Desire → Conviction → Action. (زي AIDA بتركيز على الإقناع.)
11. **AAPPA**: Attention → Advantage → Proof → Persuasion → Action.
12. **AIU**: Attention → Interest → Urgency. (بسيطة وسريعة.)
13. **PPPP**: Picture → Promise → Prove → Push.

## معادلات القصة والبناء
14. **Star-Chain-Hook**: النجم → الربط المترابط → الخطاف اللي يجبر على الأكشن.
15. **ABC Checklist**: Attain attention, Bang out benefits, Create verbal pictures, Describe success, Endorse with testimonials, Feature details, Gild with values, Honor with guarantees, Inject action, Jell with postscript.
16. **String of Pearls**: نقاط متتالية كل واحدة قوية لوحدها، مجتمعة أقوى.
17. **Cluster of Diamonds**: زي اللي قبلها بس تحت عنوان رئيسي ("5 أسباب تجرّب X النهارده").
18. **The Fan Dancer**: إغراء بالمعلومات من غير كشف كل حاجة — كل ما كنت غامض محفّز، زاد الفضول.

## معادلات الـ Direct Response الكلاسيكية
19. **Five-Point (Jack Lacy)** — 5 أسئلة: هتقدّملي إيه؟ / هتعملها إزاي؟ / مين المسؤول عن الوعود؟ / مين جرّبه قبلي؟ / هتكلّفني كام؟
20. **Nine-Point (Frank Egner)**: عنوان جذاب → افتتاحية → شرح بسيط → قصة نجاح → تقييمات → مميزات فريدة → القيمة الحقيقية → لغة تحفّز → P.S. تلخّص.
21. **Bob Stone (7 خطوات)**: ابدأ بوعد قوي → وسّع الفوائد → قول بالظبط اللي هيوصله → ادعم بأدلة → خليه يحس هيخسر لو ماتحركش → كرّر الفوائد → CTA واضحة.

## معادلات حديثة/متخصصة
22. **DDPC**: Dramatic → Descriptive → Persuasive → Clinching (الحسم النهائي).
23. **A FOREST** (دليل للمحتوى الجذاب): Alliteration, Facts, Opinions, Repetition/Rhetorical questions, Examples/Experts, Statistics, Rule of Three.
24. **SCAMPER** (تطوير الأفكار): Substitute, Combine, Adapt, Modify/Minify/Magnify, Put to other uses, Eliminate, Rearrange/Reverse/Redefine.
25. **SLAP** (منتج رخيص + صفحة قصيرة + visual مطرقع): Stop → Look → Act → Purchase.
26. **HELLYEAH** (صفحات بيع طويلة، أسلوب هجومي عاطفي): Holler → Empathize → Lambast → Legwork → Yes → Educate → Action → Handle objections.

**ملاحظة تطبيقية**: بعض المعادلات متشابهة عن قصد — المهم تعرفهم كلهم عشان متتخضش لو قابلت واحدة في مكان مختلف، وتقدر تختار الأنسب حسب المنتج/الخدمة/الهدف ونوع الصفحة (قصيرة/طويلة).
