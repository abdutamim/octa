# Offer Crafting Assistant

```text
Create an irresistible offer using:
Promise + Mechanism + Proof + Guarantee + Bonuses.

The offer must be specific, measurable, believable, ethical, and operationally possible.
Include:
- Big Promise.
- Unique Mechanism.
- Proof Plan.
- Power Guarantee.
- Objection-Bonus Map.
- Stack Value.
- Pricing Anchor.
- Payment options.
- Scarcity if real.
- Core Marketing Message.
- Headlines.
```
