# نظام التصميم — `social-v2/cafe-clone/`

## الملفات
| ملف | شغلانته |
|---|---|
| `data.js` | **المحتوى** — كل بوست + سلايداته + إحداثيات الكلام |
| `index.html` | الرندرر — بيحوّل الداتا لسلايد |

**المقاس:** 1080×1350 (4:5) · الكارت جوّه: 1028×1246

## الطبقات (ده سرّ العمق)

```text
z1  .photo     الصورة الكاملة — filter: saturate(1.06) contrast(1.03)
z2  .wash      تدرّج موضعي (w-top / w-bottom / w-left / w-full)
z3  .copy      العنوان + الكيكر
z4  .subject   نفس الشخص مقصوص ← فوق الكلام
z7  .body      النص السفلي (فوق الكل عشان يفضل مقروء)
```

**القاعدة:** الكلام (z3) بين الصورة (z1) والشخص المقصوص (z4) → بيتخبّى وراه = عمق حقيقي.
النص السفلي (z7) فوق الكل عشان ميتغطّاش.

## أنواع السلايدات (`type`)

| type | الاستخدام | حقول |
|---|---|---|
| `cover` | الغلاف | `lines` `kicker` `rail` `body` `bodyAt` `bodyCenter` |
| `teach` | سلايد شرح | `kicker` `lines` `body` `bodyAt` |
| `grid` | جريد النقط الملوّنة | `lines` `kicker` `hooks[{name,text}]` |
| `cta` | العرض + زرار DM | `lines` `kicker` `gets[]` `button` `sub` `offerAt` |

### الحقول المشتركة
```js
{
  image: "assets/photo-01.png",      // الصورة الكاملة
  cut:   "assets/cut/photo-01.png",  // المقصوصة (للعمق) — اختياري
  focus: "50% 44%",                  // object-position
  wash:  ["top","bottom"],           // أي تدرّجات
  at:    { t:150, r:56, w:880 },     // مكان العنوان داخل الكارت
  hsize: 98,                         // حجم العنوان
  lines: [{ text:"...", accent:true, in:1 }],  // in:1/2 = إزاحة
  body:  "...", bodyAt:{ b:130, r:56, w:430 }
}
```

**`at` / `bodyAt`** = `{t,r,b,l,w}` بالبكسل جوّه الكارت (1028×1246).
**`accent: true`** = اللون الأحمر · **`in: 1|2`** = إزاحة السطر (إيقاع سارة المبعثر المنظّم).

## إزاي تحدّد `at` صح

1. **افتح الصورة وشوفها.** الشخص واقف فين؟ فين الفراغ؟
2. **حط الكلام في الفراغ** — عادة فوق (الحيطة) أو على الجنب.
3. **سيب طرف الكلام يتخبّى وراه** = عمق مقصود. بس **الكلمة المهمة لازم تفضل بانة كاملة**.
4. **ارندر وبصّ.** لو مغطّى، غيّر `r` أو `w` أو `hsize`.

> صور الأهوة: أغلبها الشخص في النص والفراغ **فوق** → `at:{t:150, r:56, w:880}`.
> `photo-01` (واقف في النص) → الكلام يمين فوق: `at:{t:172, r:56, w:570}`.

## أخطاء اتعملت قبل كده — متكررهاش
1. **تغميق الصورة كلها** → الصورة بتموت. استخدم `wash` موضعي بس.
2. **حط الكلام من غير ما تبصّ على الصورة** → بيتغطّى ورا الراس.
3. **نص أبيض رفيع من غير هالة** → مش مقروء فوق الخلفيات الفاتحة.
4. **نسخ بنية الـCTA من المرجع** → بيبان كوبي. غيّر البنية (صورة + نقط + زرار بدل نص أسود مركزي).
5. **`text-align: justify` من غير كاشيدة** → كلمات مطّاطة وحشة.
