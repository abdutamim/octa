# References — How to Use This Skill in Codex, Claude, Notion, ChatGPT

## In Codex

ضع الفولدر كاملًا داخل المشروع. استخدم `SKILL.md` أو `Skill.md` كملف تعليمات.  
اطلب من Codex قراءة الملف ثم الملف المساعد المناسب.

مثال:

```text
Read SKILL.md, then read assists/04_Offer_Crafting_Assistant.md and References/03_Offer_Crafting.md. Build an offer for this brand...
```

## In Claude

ارفع:

1. Skill.md.
2. الملف المساعد المناسب.
3. المرجع المناسب.

ثم قل:

```text
Use these as operating instructions. Do not summarize. Apply the system step by step.
```

## In ChatGPT new chat

ابدأ بـ:

```text
هرفع لك Skill.md وملف مساعد. اتعامل معهم كنظام تشغيل للتسويق ولا تقفز للحل قبل التشخيص.
```

## In Notion

استورد `ALL_IN_ONE_Marketing_AI_Skill.md` كصفحة واحدة، أو استورد الفولدر كصفحات منفصلة.

## Best Practice

لا ترفع كل شيء دائمًا. ارفع حسب المهمة:

- Persona task → Skill + Persona Assist + Persona Reference.
- Offer task → Skill + Offer Assist + Offer Reference.
- Ads task → Skill + Meta Assist + Data Reference.
- Audit task → Skill + Audit Assist + Audit Reference.
