# Outputs Spec

The exact required shape of every deliverable. Nothing ships that does not match.

---

## 1. Diagnosis Report
```markdown
**Symptom:** [what the user sees]
**Real bottleneck:** [one link in the chain]
**Evidence:** [what points to it]
**What we are NOT fixing now:** [and why]
**First action:** [today]
```

## 2. Positioning Sheet
```markdown
**Focus sentence:** I help [who] who feel [tension] by [mechanism] — and I do not help [who not].
**Niche score:** [x/30, six criteria]
**Differentiation:** [what only they can say]
**Enemy:** [the idea we argue against]
```

## 3. Persona File
See `references/03-persona-awareness.md` — description, psychological map,
buying behaviour, 3 verbatim quotes, top 3 objections, awareness stage, CTA ceiling.

## 4. Offer Doc
```markdown
**Name** · **Promise** · **Mechanism** · **Deliverables** · **Proof**
**Guarantee** · **Bonuses** · **Price (3 tiers)** · **Who it is NOT for**
```

## 5. Brand Sheet
Name + rationale · logo direction (type, 3 concepts, generation prompt) ·
palette (4 hex, 60/30/10) · type (2 families) · filled `vibe.json` ·
moodboard brief · anti-style list · profile copy.

## 6. Content System Sheet
Pillars (3–5, each with 20-idea justification) · 3C weekly split · named
repeatable series · anchor cadence · formats in rotation · visual signature.

## 7. Hook Bank
**30 literal hooks**, tagged by type and pillar. No placeholders — every hook
is publishable as written.

## 8. 30-Day Plan
CSV matching `30-day-plan-template.csv`. 30 distinct rows. Every row has a
literal hook. Plus batch days and 4 retro days.

## 9. Post Packages (at least 5 fully built)
```markdown
Stage · Pillar · Format · Hook (literal) · Visual hook (frame at 0s)
Full script or slide-by-slide text · On-screen text · B-roll list
Caption · One CTA · KPI
```

## 10. Carousel Spec
Table: `slide # · form · literal text · font size · hex · position (% height) · image · note`

## 11. Landing Page Copy
The 10 sections from `references/07-copywriting.md`, written out in full.

## 12. Ads Plan (if budget > 0)
Structure · 3–5 angles · unit margin · max allowable CAC · break-even ROAS ·
measurement checklist · kill and scale rules.

## 13. Scale Sheet (if already producing)
Current level · freedom test result · the one unlock · 4-3-2-1 · systems status ·
first thing to delegate · next 90-day audit date.

## 14. Measurement Sheet
Metric per stage · weekly review questions · the single change rule.
