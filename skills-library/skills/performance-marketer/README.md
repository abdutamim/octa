# Performance Marketer

سكيل تشغيلي كامل للـ Performance Marketing و Growth، باللهجة المصرية + المصطلحات الإنجليزية. من أول ما تفكر لغاية ما تطلق إعلان وتعمل Scaling — A→Z.

## البنية

```text
performance-marketer/
├── SKILL.md          ← العقل: الهوية + المبادئ + بروتوكول التشخيص A→Z + جدول التوجيه
├── references/        ← الطبقة العميقة (26 ملف: موسوعة + frameworks + templates + checklists)
├── assists/           ← launchers جاهزة لكل مهمة
└── assets/            ← صور مرجعية (عجلة المشاعر، Pricing Page، CTA colors)
```

## إزاي بيشتغل

الـ `SKILL.md` بيتحمّل وبيقود القرار. لما تيجي مهمة عميقة، بيفتح ملف الـ reference المتخصص من `references/` الأول (framework + template)، وبعدين ينفّذ. ده بيخلّي الملف الأساسي خفيف والدقة عالية (progressive disclosure).

## أهم الملفات الجديدة
- `19_AOV_Monetization` — رفع الـ AOV والـ cross/up/down-sell والـ thank-you page.
- `20_Email_Marketing` — Deliverability + Welcome Sequence (AIM) + Lead Magnet.
- `21_Copywriting_Formulas` — 26 معادلة كوبيرايتنج.
- `22_Meta_Account_Structure_2026` — ستراكتشر الأكونت والسكيلينج (تحديثات ميتا الحديثة).
- `23_Pricing_Strategies` — استراتيجيات التسعير بمعادلات وأمثلة.
- `24_Copy_Direction_Workshop` — ورشة كتابة الكوبي في 7 خطوات: Copy Direction → Draft → Value → وظيفة كل جملة → CTA حسب الـ Awareness → Variations → مسطرة تقييم من 25.
- `25_Copy_Formulas_Persona_Mapping` — تفكيك 10 فورمولات (AIDA/PAS/BAB/FAB/4Ps/QUEST/PASTOR/ACCA/SSS/HSO) وربط كل مكوّن بحقله في الـ Persona Sheet + جدول اختيار سريع.
