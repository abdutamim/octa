# نظام التصميم والرندر — أي براند

القالب المرجعي الشغّال: `social-v2/cafe-clone/` (انسخه وبدّل الهوية).

## الملفات
| ملف | شغلانته |
|---|---|
| `data.js` | **المحتوى** — كل بوست + سلايداته + إحداثيات الكلام |
| `index.html` | الرندرر — بيحوّل الداتا لسلايد |
| `style.css` | الهوية (ألوان، خطوط، الطبقات) |
| `export.mjs` | Playwright → `out/<id>-<slug>/01..NN.png` + `PREVIEW.png` |
| `cutout.py` | rembg — بيقص الشخص من الصورة → عمق |
| `normalize.mjs` | sharp — بيوحّد أي صور على 1080×1350 |
| `split-pano.mjs` | بيقسّم بانوراما 3:1 لـ٣ مربعات للجريد |

**المقاس:** 1080×1350 (4:5) · الكارت جوّه: 1028×1246

## الطبقات (سرّ العمق)

```text
z1  .photo     الصورة الكاملة — من غير تغميق عام
z2  .wash      تدرّج موضعي (top / bottom / left / full)
z3  .copy      العنوان + الكيكر
z4  .subject   نفس الشخص مقصوص ← فوق الكلام
z7  .body      النص السفلي (فوق الكل عشان يفضل مقروء)
```

الكلام (z3) بين الصورة (z1) والشخص المقصوص (z4) → بيتخبّى وراه = **عمق حقيقي**.

### الحقول المشتركة
```js
{
  image: "assets/p01.png",       // الصورة الكاملة
  cut:   "assets/cut/p01.png",   // المقصوصة (اختياري — للعمق)
  focus: "50% 44%",              // object-position
  wash:  ["top","bottom"],       // أي تدرّجات

  hsize: 98,
  lines: [{ text:"...", accent:true, in:1 }],  // accent = لون الضربة · in = إزاحة
  body:  "...", bodyAt:{ b:130, r:56, w:430 }
}
```

## إزاي تحدّد مكان الكلام صح

1. **افتح الصورة وشوفها.** الشخص واقف فين؟ فين الفراغ؟
2. حط الكلام **في الفراغ** (عادة فوق).
3. سيب **طرف** الكلام يتخبّى وراه = عمق مقصود — بس **الكلمة المهمة تفضل بانة كاملة**.
4. **ارندر وبصّ.** لو مغطّى، غيّر `r` / `w` / `hsize`.

> لو الصورة زحمة أو الشخص في النص: **خلّي السلايد خلفية مصمّمة** (`textbg`)
> بدل صورة. ده بيحل المشكلة من جذورها.

## أوامر

```powershell
node export.mjs                       # رندر الكل
node normalize.mjs                    # توحيد مقاسات الصور -> 1080×1350
py   cutout.py p01 p02                # قص الشخص
node split-pano.mjs pano.png P1       # تقطيع بانوراما (تُنشر بالعكس 3→2→1)
```

**توليد صور بجيمناي:**
```powershell
node ../gen.mjs --out=... --ref=face.png --prompt="[face-lock] ..."
```
- أي صورة فيها وش شخص حقيقي → **رسالة حماية الملامح إلزامية** + `--ref`.
- Gemini بيكسّر الحروف الإنجليزية في الـ3D — **ولّد الصورة بدون نص**
  واكتب التايبوغرافي بالكود.
- **outpaint** لتوسيع صورة لاندسكيب: «extend upward, preserve every pixel,
  continue the background, leave the new area clean for text».

## 🚨 أخطاء اتعملت قبل كده — متكررهاش

1. **تقسيم العربي لحروف في spans** → بيكسر تشبيك الحروف. استخدم `clip-path`.
2. **تغميق الصورة كلها** → الصورة بتموت. wash موضعي بس.
3. **حط الكلام من غير ما تبصّ على الصورة** → بيتغطى ورا الراس.
4. **كتّاوت من صورة تانية** فوق صورة → بيطلع شخصين في الفريم.
5. **نص أبيض رفيع من غير هالة** → مش مقروء فوق الخلفيات الفاتحة.
6. **نسخ بنية الـCTA من المرجع** → بيبان كوبي. غيّر البنية.
7. **`text-align: justify` من غير كاشيدة** → كلمات مطّاطة وحشة.
8. **تداخل الـSequences** (في الفيديو) → عنصر يظهر فوق التاني. راجع الأرقام.
