# The Library — 94 references, read one by one

Built 2026-08-05 by opening all 94 slides in `learn/` and transcribing what is
written inside them. The rest of this skill holds the **averages** of those 94.
This file holds the **specimens** — and the specimens are what stop every brand
coming out looking the same.

> **Rule of use:** pick ONE content archetype, ONE layout family, ONE colour
> strategy per post, and write them into the brand's kit. Never let the
> renderer's defaults choose for you. If two brands share all three, one of
> them is wrong.

---

## 0. The thesis (the reason this file exists)

> **"Every carousel that gets saved tells its story three ways at once: what
> you say, how it's built, and how it looks. Most people only write the words.
> That's why they flop."**

Three layers, and all three must be decided per brand:
**SAY** = archetype + hook + copy · **BUILT** = beat structure + slide arc ·
**LOOKS** = layout family + colour strategy + type.

---

## 1. SAY — content archetypes (pick one per post)

**"You don't have a content problem. You're using the wrong archetype for the
outcome you want."**

| Archetype | What it is | Wins |
|---|---|---|
| **The System** | The whole process, numbered, with a rule you don't break | saves — *"nobody can hold six rules in their head"* |
| **The Formula** | One skill broken into **named** parts. Naming them is what makes it yours | saves + authority |
| **The Teardown** | Before and after, **change exactly one thing** | shares — *"people send it to someone who needs it"* |
| **The Confession** | Honest admission with the lesson attached | follows + comments, **not** saves |
| **The Template** | Not a post they read — a thing they **use** | comments + DMs |
| **The Vault** | 17 skills, 20 formats, 50 hooks — impossible to memorise | highest save rate of any type |

**Confession gate:** *"Share from a scar, healed, with the takeaway. Never a
wound that's still bleeding."* Ask: am I teaching from this, or just bleeding
on the page? No transferable lesson yet → it's a journal entry, keep it.

## 2. BUILT — the six beats, and the spine test

| Beat | Rule |
|---|---|
| **1 Cold Open** | Open at the most interesting moment, then back up. Don't introduce the topic — drop them inside it. *"Your first slide isn't a title. It's the cliff edge."* NOT "I want to talk about storytelling" → YES "I deleted 40,000 followers on purpose" |
| **2 Mirror** | Say the sentence they've thought but never admitted. *"If they don't feel caught, you haven't mirrored them yet."* |
| **3 Spine** | Every slide must end **owing the next one a reason to swipe**. A carousel isn't a list, it's a sequence, and the order is the argument |
| **4 Rhythm** | Change the **visual weight** every slide. One-word slide, then a dense one, then a full-bleed image, then a colour flip. *"The same energy on every slide reads as one long slide."* |
| **5 Turn** | Never *"here's what I learned"* — always *"so you can ___"*. **This is the slide they screenshot; make it the sharpest line in the set** |
| **6 Payoff** | Flip a belief, then give one specific action. *"A carousel that doesn't close is just content. One that closes is a funnel."* |

**THE SPINE TEST — run it on every deck:**
> Cover any slide. If the next one still makes sense without it, **your spine
> is broken.**

**Beat maps** (both were measured off real decks — use either, not a blur of both):

```
6-slide   Setup 1-2 · Tension 3-5 · Payoff 6
10-slide  1 hook · 2-3 interest via live examples · 4-5 hold with images
          6-9 immediately executable info · 10 CTA          (A.I.D.A / P.A.S)
```

## 3. Hooks — the six Arabic types, verbatim

| Hook | Rule |
|---|---|
| **هوك الفضول** | ما تقولش كل حاجة من على الباب. سيب حاجة تخليه يدخل مكانك |
| **هوك الإحساس** | تقول موقف هو عايشه كل يوم، فيحس إن البوست بيتكلم عنه هو بالتحديد |
| **هوك الصدمة** | تبدأ بحاجة عكس المتوقع، فيقف عندك من غير ما يحس إنك قفشته |
| **هوك الصورة** | لقطة مختلفة أو زاوية أو تكوين **يوقف العين قبل ما يقرا** |
| **هوك الوعد** | توضّح له هيطلع منك بإيه — وقته عندك له قيمة |
| **هوك الخوف** | توريه غلطة ممكن يقع فيها أو حاجة بتضيّع عليه نتيجة |

Supporting laws:
- *"البوست بيقفش زبونه من أوله، **قبل ما يقرأ العنوان حتى**"*
- *"الهوك هيجيبه، والمحتوى هيقعّده"* — hook brings them, content seats them.
- *"لو المحتوى فاضي، أقوى هوك في الدنيا هيبان كأنه خدعة"* — and it backfires.
- Three-tier hook craft: beginners write headlines they *think* are clever ·
  amateurs copy winning headlines verbatim · **pros understand why a headline
  won, then rebuild it in their own voice for their own audience.**

## 4. LOOKS — the twelve layout families

Each is a **skeleton**, not a style. Assign one per post; rotate across the grid.

| # | Family | Skeleton |
|---|---|---|
| **F1** | **Numbered Chapter Plate** | Letterspaced ordinal + hairline pinned top-left → small "the" → oversized serif noun ~7% → bold deck → 1–2 ragged body columns → a payload rack in the lower third (discs / cards / chips / boxes). Same template, wildly different grounds |
| **F2** | **Rotated Ordinal** | Giant ordinal word rotated 90°, 28–35% of frame height, bleeding off the left edge → headline + italic kicker in the right 70% → tilted mockup entering from the bottom, **cropped by at least one frame edge** so it reads as a real object |
| **F3** | **Rule Card** | Micro rail → outlined `Rule N` pill → ONE lowercase hero word at 6–10% → one-line sub → 2-up wrong-vs-right mockups → 1–3 line footer verdict. Centred on a single axis |
| **F4** | **Cinematic Wordmark** | 3-cell micro rail (`DATE · HANDLE · CATEGORY`) → full-bleed scene → one display word at 10–16% over the horizon → **subject cut out and interleaved with the letterforms** so type and image share a depth plane |
| **F5** | **Blank Field** (AR) | Off-white ground, small centred handle → ONE right-aligned two-tier block (bold hook + light body) between 29–56% → hand-drawn swipe arrow ending the block → **45–55% of the frame deliberately empty** → IG-action footer bar |
| **F6** | **Photo-Card Poster** | Rounded photo card floating on black with a ~4% margin, chrome pinned to the black → hand-lettered eyebrow inside a drawn ellipse → oversized display headline → small kashida-justified body |
| **F7** | **Wiring Diagram** | Bicolour gradient title → tiers of slide thumbnails joined by **heavy bracket connectors**, each tier tagged `الشريحة NN` + a one-line spec. The connectors carry the meaning |
| **F8** | **Contact Sheet** | 2×2 grid with the **fourth cell deleted** and replaced by name lockup + paragraph; handle top-left, date top-right, services bottom-left, CTA bottom-right; one saturated ground |
| **F9** | **Dark Stat** | Centred avatar+handle lockup → near-empty dark field → headline with exactly ONE accent word → screenshot/device in the middle band → **ghost numeral at 16–17% of frame height, 8% opacity, bleeding off a corner** |
| **F10** | **Rule → Demo** | Gradient headline, then 3 stacked pairs of [one-line rule] + [vector demo of that rule executed directly beneath]. Footer page chips |
| **F11** | **Proof Grid** | Centred lockup + pill → symmetric array of artefacts that carries the argument (4 products over 4 hex tiles; Before card beside After) → bottom rail. **The claim is never asserted in prose** |
| **F12** | **Void CTA** | No image. Flat black or flat colour, centred stack, ~45% dead space, greyscale hierarchy, and **only the keyword at full white** |

**Type-specimen variant of F4:** the font name set **in its own face** at 13–16%
of frame height, sitting on the photo's horizon, mood label beneath —
`Inter → Smart & Minimalism` · `Tempting → Elegant & Romantic` ·
`Tan Mon Cheri → Fashion & Editorial`.

## 5. The five premium rules

> **"You don't need a designer or a budget. You need five rules you actually keep."**

| Rule | Law |
|---|---|
| **contrast** | One colour that pops beats a flat wash. Pick one hero colour and let it hit |
| **restraint** | One enhancement beats five stacked. *Amateur piles on effects. Premium picks one and commits* |
| **locked palette** | The same few colours every time. *A new colour scheme every post is exactly why it never reads as a brand.* Lock 3–4, never break them |
| **two fonts** | Two fonts. The same two. Always. *Four fonts because you can is the fastest tell* |
| **space** | Room to breathe beats crammed corners. **Empty space reads as confidence, and confidence reads as premium** |

**Cover rules** (proved before/after on the same artwork, never asserted):
1. Make text bold, big & easy to scan — *if it's small, it'll fail*
2. Use strong visuals that support the message — *a powerful image > generic stock*
3. Make the hook clear & benefit-driven — *one cover, one message, delete the rest*
4. Use contrast — *high contrast = high attention*
5. Keep it clean, focused & on-brand — *simplicity builds trust*

> **"your content is great. your cover is why nobody sees it."**

## 6. How the eye actually moves

- **Named scan paths:** `مسار العين (Z)` and `مسار العين (F)` — pick one and
  place the payload on its terminal node.
- *"الكاروسيل لا يُقرأ بل يُمسح بعين سريعة"* — a carousel is scanned, not read.
- *"العين لا تقرأ كل كلمة، بل تبحث عن الكلمات المهمة أولًا"* → set key words in
  a heavier weight or a different colour. Demonstrated as ❌لا تفعل / ✅افعل on
  the **same sentence at the same size**, so the highlight is the only variable.
- **The three contrast axes**, and they are enough on their own:
  `الكبير مقابل الصغير` · `الفاتح مقابل الغامق` · `القصير مقابل الطويل`
- Hierarchy: different sizes AND weights · cut words, leave more space ·
  **one idea per slide**.
- **Never `#000000`.** Use `#161616` · `#232323` · `#2C2C2C` · `#363636`.

## 7. CTA bank — five goals, five lines each

**Mechanic:** *"'Save this' is weak. 'Comment PREMIUM' is strong."* A keyword
comment beats a save prompt. Trigger words go in guillemets «».

**تعليقات:** شو أكبر تحدي عم تواجهه بهالموضوع؟ · تتفق أو تختلف؟ وليش؟ · لو بدك تضيف نقطة وحدة، شو بتكون؟ · أي نقطة حسيت إنها بتحكي عنك؟ · جاوبني بكلمة وحدة.

**متابعة:** إذا هدفك تكبر حسابك، تابعني. · هاي البداية فقط، والجزء الأقوى جاي. · كل أسبوع بنزل أدوات جاهزة. · إذا بدك تتعلم بالممارسة، تابعني. · تابع حتى ما يفوتك الجزء الجاي.

**حفظ:** احفظه، رح ترجعله أكثر من مرة. · خليه عندك كمرجع قبل ما تنشر أي محتوى. · لا تعتمد على ذاكرتك، احفظه. · إذا بتشتغل بالمحتوى، لازم يضل عندك. · هذا من البوستات اللي رح تشكر نفسك لأنك حفظته.

**DM:** اكتب «خطة» وببعتلك إياها. · ابعتلي «هوكات» وبوصلك الملف. · اكتب «جاهز» إذا بدك التفاصيل. · ابعتلي «قالب» وبشاركك النموذج. · إذا بدك الملف كامل، ابعتلي كلمة «محتوى».

**مشاركة:** ارسله لشخص لازم يشوف هالمعلومة اليوم. · إذا عندك صديق بيصنع محتوى، شاركه معه. · يمكن هالبوست يختصر على حدا أشهر من التجربة. · إذا فادك، وصّله لغيرك. · شاركه مع فريقك بدل ما تشرحلهم من الصفر.

## 8. Devices worth stealing (each observed at least once)

- Card **cropped by two frame edges** so it reads as a physical object half out of frame.
- **Leader lines** pulling labels off a mockup's edge — turns a static image into an annotated diagram.
- An element from **inside** a card echoed **outside** it at 3× size, with a hand-drawn arrow curving back.
- Discs on an **arc**, not a straight column, mirroring a card's rotation.
- The photo's **own horizon** used as the layout divider — dark band takes white type, light band takes white cards. No container needed.
- Subject planted so it **splits the sub-headline** in two.
- Type built as a **manufactured object** (neon bolted to plate) — the type is the photograph, not on it.
- Two cards at **opposing rotations** overlapping into a V — the stacking *is* the before/after argument.
- One accent swapped on **one** element (a black pill turned lime) to pre-select the winner before the reader compares.
- **The slide enacts its own rule**: the contrast lesson uses only contrast; the rhythm lesson drops to full greyscale after five saturated slides; the "flat wash is amateur" slide sits on a flat wash.
- **Screenshot impersonation** — build the slide as a native tweet/post so it reads as overheard rather than designed.
- A **ghost numeral** larger than any readable type on the slide, at ~8% opacity.

## 9. Anti-patterns — what "everything looks the same" actually is

Diagnosed from this skill's own output, 2026-08.

| Symptom | Cause | Fix |
|---|---|---|
| Every brand reads the same | The chassis is hardcoded: one centred vertical stack, brand identity can only enter as paint | Assign a **layout family (F1–F12)** per brand in its kit; the renderer reads it |
| Every post reads the same | One archetype used every time (explainer) | Assign an **archetype** per post; rotate |
| Every headline reads the same | One copy pattern: 2 lines, accent on line 2 | Vary per brand: stepped stairs, 2×2 word grid, one word per line, kashida stretch, split by the subject |
| Nothing feels premium | Frame filled edge to edge | **Empty space reads as confidence.** F5 and F12 leave 45–55% empty on purpose |
| Every deck is 5 slides, same arc | Default formula | Pick a beat map (6-slide or 10-slide AIDA) from the archetype |
| Colour always "one accent ≤10%" | Restrained by reflex | Choose deliberately: **restrained / committed / full-palette / drenched**. A luxury studio may well be drenched |
| Before/after proves nothing | More than one variable changed | **Change exactly one thing.** Same artwork, same size, same copy — one variable |

## 10. Per-brand kit — the fields that must be decided

Tokens alone (hex, fonts, radii) are **paint**. These are the architecture:

```
archetype      which of the 6 / 5 Arabic formats
beat map       6-slide or 10-slide AIDA
layout family  F1–F12 (and which family the COVER opens on)
colour strategy restrained | committed | full-palette | drenched
alignment      centred | ragged-right | ragged-left | edge-anchored | mixed
density        % of frame deliberately left empty
type scale     hero as % of frame height + how many sizes per slide
image role     bleed | inset | cut-out | mockup | none
hook type      which of the 6
CTA goal       comments | follows | saves | DMs | shares  → pull the lines
anti-reference the look this brand must NOT resemble
```

**Two brands may not share all of these.** If they do, one of them has not been
designed — it has been rendered.
